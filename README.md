# Билим Жолу: ата-энелердин пикири

Ар бир класс жетекчинин өз шилтемеси бар. Ата-эне WhatsApp'та мугалимдин сүрөтү бар
карточканы көрөт, басканда Airtable формасы дароо ачылат.

Шилтеме: `https://bakytkg.github.io/shilteme/<slug>/`

## Жаңы мугалим кошуу

1. Airtable'да мугалимдин формасын жасаңыз («Мугалим» талаасы ошол мугалимге коюлуп, жабык болсун).
2. Мугалимдин сүрөтүн `photos/<slug>.jpg` деп салыңыз (3:4, мисалы 600×800).
3. `teachers.json` файлына бир жазуу кошуңуз:

   ```json
   {
     "slug": "familiyasy",
     "name": "Фамилиясы Аты Атасынын аты",
     "role": "3-А класс жетекчиси",
     "form": "https://airtable.com/appss2GhR4Xpse3uw/pag.../form"
   }
   ```

4. `python3 tools/build.py` иштетиңиз. Ал `og/<slug>.jpg` карточкасын жана `<slug>/index.html` барагын түзөт.
5. Өзгөрүүлөрдү GitHub'га жүктөңүз.

`slug` латын тамгалары менен, боштуксуз жазылат (мисалы `ashymbaeva`).

## Эскертүү

WhatsApp шилтеменин карточкасын бир жолу жүктөп, эсинде сактайт. Сүрөттү алмаштырсаңыз,
шилтеменин аягына `?v=2` кошуп жөнөтүңүз.
